All three run end to end from a clean clone — no manual data downloads, no Docker. Each ships with a validation suite. All data is synthetic and contains no PHI.

HL7 v2 Interface Monitor

Parses HL7 v2 message traffic and validates it against 21 rules spanning message structure, the MSH header, patient and visit segments, and order and result segments. Severities map to what actually happens to a message: rejected outright, or filed anyway with a defect inside it. Verified by a 173-check self-test plus a generator-to-detector reconciliation reaching 1,047 of 1,047 injected faults detected.

Stack: Python (standard library only) · HL7 v2 · synthetic, no PHI

30-Day Readmission Analytics & HRRP Risk

A Caboodle-style star schema over 12,000 synthetic inpatient encounters, with 30-day all-cause readmissions flagged by LAG/LEAD window functions and stratified across the six CMS HRRP conditions. Slowly Changing Dimension Type 2 on the patient dimension, so a 2023 encounter stays joined to where that patient lived in 2023. 25 validation checks.

Stack: PostgreSQL · SQL · Python · Tableau · synthetic, non-PHI
github.com/gadesaiharika/hrrp-readmission-analytics →

Revenue Cycle Denials & AR Analytics

A three-grain billing warehouse over 85,000 synthetic claims and 480,000 remittance postings, computing Denial Rate, First-Pass Yield, Net Collection Rate, and Days in AR. The CARC taxonomy separates true denials from contractual write-downs and patient responsibility — a distinction that moves the reported denial rate from over 90% to 11%. 39 validation checks, including the claim-level financial identity asserted to the cent.

Stack: PostgreSQL · SQL · Python · synthetic, non-PHI
